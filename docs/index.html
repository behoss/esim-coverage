About this data

Each row is a country a travel eSIM covers, with every mobile network (operator) the eSIM can connect to there and the network types each one offers. The data comes from the live catalogue at eSIMology, where every travel eSIM is delivered by email in about a minute.

  • Files: coverage.json (one object per country) and coverage.csv (one row per country and network).
  • Columns: iso2, country, operator, network_types, best_network, esim_url.

  • Source code and schema: github.com/behoss/esim-coverage.
